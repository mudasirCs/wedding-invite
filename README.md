# Wisteria Balcony Wedding Invite

Recreation of [wooowinvites demo-5f7e70](https://www.wooowinvites.com/invite/demo-5f7e70) (Wisteria Balcony).

## Flow

1. Sealed gate + “For John and Maria” → Tap to open  
2. Wisteria door opening animation  
3. Balcony mist theme + scrollable blocks + music  

## Run

```bash
cd /home/md/royal-invite
npm run dev
```

Edit `src/data/invite.ts` for real couple details.
